# Запуск / обновление Roomly 1.4

Для существующего проекта используйте [инструкцию Phone Auth](docs/PHONE-AUTH.md).

Порядок: резервная копия → preflight на копии → миграция 006 на копии → проверка ролей и истории → миграция 006 рабочей базы → обновление файлов GitHub Pages → приёмка SMS и входа.

На НОВОЙ пустой базе сначала применяются 001_schema.sql, 004_registered_members.sql, 005_employee_registration.sql, затем 006_phone_identity.sql. Первый администратор настраивается через 003_first_admin.sql с вашим email, после чего должен зарегистрировать и подтвердить этот адрес. На существующей базе повторно не создавайте схему 001. После 006 не запускайте старые миграции функций 003/004/005.

Требуются действующие Supabase URL и публичный ключ в config.js. Секретные ключи, пароль базы и SMS-токены в сайт не помещаются. В архив обновления config.js не входит: сохраняйте свой файл.

Репозиторий: https://github.com/rafwonko-stack/roomly
Сайт: https://rafwonko-stack.github.io/roomly/

Загружайте содержимое архива в корень репозитория с заменой, без дополнительной вложенной папки. index.html должен оставаться рядом с assets. Дождитесь успешной публикации Pages и обновите страницу Ctrl+F5.
