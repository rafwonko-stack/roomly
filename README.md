# Roomly 1.4 — телефон +996 и пароль

Инструкция обновления существующего проекта: [docs/PHONE-AUTH.md](docs/PHONE-AUTH.md).

Регистрация и вход через Supabase Phone Auth; SMS-подтверждение, восстановление пароля после проверки номера, привязка телефона к текущему аккаунту. Email-вход сохранён на период перехода. Клиентский Google OAuth удалён.

Права привязаны к auth.users.id. Новые регистрации получают employee; роли назначает администратор. Миграция 006 сохраняет существующие роли, блокировки, записи бронирований и историю. Применяйте её сначала на копии базы по инструкции. Старые миграции после 006 повторно не запускайте.

`config.js` не изменён. Рабочая база, SMS-провайдер и настройки Supabase не менялись. Реальные SMS нужно проверить после подключения провайдера.

Клиент: HTML/CSS/JavaScript без фреймворка. Исходники в assets/app.js, api.js и core.js; bundle собирается командой `npm run build`. Проверки: `npm run check`, `npm test`; SQL и DOM: `npm ci --prefix tests/integration`, затем `npm run test:integration`.

Логотип банка и Geologica хранятся локально; лицензия шрифта — assets/fonts/OFL.txt. Остальные страницы используют существующее оформление.
