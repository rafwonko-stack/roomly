# Roomly 1.6

Внутреннее бронирование залов Элдик Банка. Вход только по Email и паролю. Аккаунты создаёт администратор в разделе «Сотрудники» через защищённую серверную функцию Supabase.

Подключение и обновление: [ADMIN-ACCOUNTS.md](docs/ADMIN-ACCOUNTS.md).

Сборка: `npm run build`. Проверки: `npm run check`, `npm test`. Дополнительные SQL/UI-проверки: `npm run test:integration` (зависимости из tests/integration/package.json).

Конфигурация и база при обновлении сохраняются. Публичной регистрации и восстановления пароля нет. Функцию create-employee необходимо отдельно развернуть в Supabase.
