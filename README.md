# Roomly / Элдик Банк — версия 1.3

Сервис бронирования конференц-залов: HTML, CSS и JavaScript без клиентского фреймворка. GitHub Pages размещает интерфейс, Supabase хранит аккаунты, роли и бронирования.

**Начните с [START.md](START.md).** Параметры базы в config.js пока пустые. Это готовый к подключению код, а не уже развёрнутая облачная система.

- Обычная регистрация создаёт сотрудника на стороне базы; email нужно подтвердить.
- Вход, повторное письмо подтверждения, восстановление и смена пароля.
- Администратор видит зарегистрированных пользователей, меняет роли и отключает доступ. Самопонижение запрещено.
- Расписание на день/неделю, каталог залов, собственные встречи и история за год.
- Бронирования сохраняются в PostgreSQL. Перезапуск браузера и смена дня их не удаляют.
- Пересечения запрещены ограничением базы, права проверяются в серверных функциях.
- Geologica, официальный логотип банка, синяя палитра, зелёные метки оборудования.
- Адаптивная навигация и формы; широкое расписание и таблицы прокручиваются внутри блока.
- Демоаккаунты, локальные бронирования и переключатель ролей удалены из приложения.

Исходный код: assets/app.js, api.js, core.js. После изменений выполните `npm run build`, чтобы обновить app.bundle.js.

Проверки: `npm test`, `npm run check`. Для интеграционных проверок сначала `npm ci --prefix tests/integration`, затем `npm run test:integration`.

Проверено 36 модульных/HTTP тестов, SQL-проверки прав, пересечений, регистрации и истории, сценарии интерфейса через Happy DOM. Реальный почтовый сервис и облачная база пока не подключены. Визуальная проверка в браузере этой среды заблокирована тайм-аутом локального адреса; окончательная проверка на телефоне и компьютере нужна после публикации.

Регистрация открытая: любой подтвердивший email получает сотрудника, как запрошено. Это не ограничение по корпоративному домену.
